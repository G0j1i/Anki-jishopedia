# Ankipedia Release Notes

## New Features

- **Right-click to Block Words:**  
  You can now right-click on any underlined term during review to instantly block it from showing Wikipedia tooltips. This makes it easy to hide unwanted terms without leaving your study session.

- **Themes:**  
  Choose between Light and Dark themes for tooltips and context menus. The appearance of Ankipedia tooltips will match your preference for a more comfortable study experience.  
  _Note: Auto theme (system-based) is coming soon!_

- **Custom Settings Bar:**  
  The new settings dialog allows you to:
  - Select your preferred Wikipedia language.
  - Customize the class name for tooltip activation.
  - Adjust border style, thickness, and color for underlined terms.
  - Set tooltip button background and text colors.
  - Manage blocked words and unigrams directly.

Enjoy a more personalized and streamlined Ankipedia experience!
